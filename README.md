
# Little Lemon Restaurant Booking App

A responsive restaurant reservation interface built with React and Vite as part of the Meta Front-End Developer course on Coursera.

## Features

- Responsive restaurant homepage and navigation
- Table reservation form
- Date, time, guest count, and occasion inputs
- Client-side form validation
- Reservation confirmation display
- Accessible form labels and error messages
- Unit tests using Vitest and React Testing Library

## Technologies

- React
- JavaScript (JSX)
- Vite
- CSS
- Vitest
- React Testing Library
- ESLint

## Requirements

Install Node.js and npm before running the project.

## Installation

Clone the repository and open its folder:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd little-lemon-booking
npm install
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

## Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Run tests

```bash
npm test
```

The test runner starts in watch mode. Press `q` to quit.

## Production build

```bash
npm run build
```

## Code quality

```bash
npm run lint
```

## Booking limitations

This project currently demonstrates a reservation form and client-side confirmation. It does not connect to a live restaurant booking API or database, and it does not verify real table availability.

## Project status

The interface, client-side validation, unit tests, production build, and lint checks have been implemented. Further work may include booking API integration and additional tests.
